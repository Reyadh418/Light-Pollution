# Supplementary Documentation & Project Presentations

This directory contains supplementary presentations, project overviews, early working drafts, and contextual factsheets developed during the research project:
**"An IoT-Based Infrastructure Model for Reducing Urban Light Pollution: Empirical Assessment and System Design in Dhaka"**
by Md Reyad Hasan and Ishrat Jahan Riya.
